# Handover: Open Service Broker for CAPI Navigator

Starting kit for a separate project: an Open Service Broker (OSB) for Cloud Foundry that offers the
cluster blueprints of CAPI Navigator (FP-34, outlook FP-35 in [requirements.md](../../requirements.md)).

| File                               | Goes to                      |
| ---------------------------------- | ---------------------------- |
| [CLAUDE.md](CLAUDE.md)             | `CLAUDE.md` of the new repo  |
| [requirements.md](requirements.md) | `docs/requirements.md` there |

How to start: create the repository, copy both files, open Claude Code in it and let it begin with
pack OSB-0. The first session settles the open decisions listed in section 9 of the requirements,
one at a time.

Prepared on 2026-11-03 against CAPI Navigator with FP-34 (first release after 0.15.0) and the
Open Service Broker API v2.17.
